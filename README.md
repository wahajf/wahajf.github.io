# Wahaj Farooq — Next.js Personal Portfolio

This is a modern **Next.js 14 App Router** personal website built for **Wahaj Farooq** (Developer & Aviation Creator based in Vancouver, BC).

---

## ⚡ Features
- **Next.js 14 App Router** architecture with Server & Client components.
- **Top Floating Pill Navigation**: Center black capsule navbar with Sun/Moon theme switcher & yellow active tab highlight (`#eab308`).
- **Product Designer Layout**: Circular avatar initials, authentic intro copy structure, filterable tab selector (**Work**, **Feed / Media**, **Experience**).
- **Project Cards**: Clean title + date, `@thatyvrspotter` embedded video player, and `Website ↗` / `GitHub ↗` pill buttons.

---

## 🚀 How to Run Locally

```bash
# Navigate to project folder
cd /Users/wahaj/.gemini/antigravity/scratch/personal-profile

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 How to Deploy to Vercel (1-Click)

1. Push this repository to GitHub.
2. Import the repository on [Vercel](https://vercel.com).
3. Vercel automatically detects Next.js and deploys your website live!
